# 月夜のコーヒーノキ

お月さまとコーヒーノキのお話。

ある涼風の日の夜、コーヒーノキはお月さまにたずねます。

『わたしの実のかおり、あなたに届いてますか』

お月さまが教えてくれたのは、それぞれの時間のなかにいるコーヒーノキのなかまたちのこと。

お月さまとコーヒーノキの願いに包まれた、静かでやさしい絵本です。

絵・文章：amane  
制作：Mauri & Rafi

## この絵本について

「月夜のコーヒーノキ」は、さまざまな読み方で楽しめることを目指して制作したインクルーシブ絵本です。

- 絵と文章を見て読む
- スクリーンリーダーで読む
- 朗読を聞きながら、文字のハイライトを追う

読み方や利用する端末に合わせて、複数の形式を用意しました。

## 絵本をダウンロードする

PDF・EPUBは [GitHub Releases](https://github.com/corriedale99/Tsukiyo-no-Kohinoki/releases) から無料配布する予定です。

| 形式 | 特徴 |
|---|---|
| PDF | 本文の読み順と画像の代替テキストに配慮したPDF |
| EPUB | 音声なしの固定レイアウト電子書籍 |
| Read Aloud EPUB | 朗読音声と文字ハイライトが同期するEPUB |
| Dolphin EPUB | Dolphin EasyReader向けのリフロー型EPUB。朗読・ハイライト付き |

### PDFのアクセシビリティ

Macのプレビュー＋VoiceOver、およびWindowsのEdge＋NVDAで読み上げを検証しています。

本文の読み順と主要画像の代替テキストを確認し、装飾図形による不要な読み上げを抑える調整を行いました。

PDF/UA-1への完全準拠を示すものではありません。

### EPUBの利用について

通常EPUBとRead Aloud EPUBは、Apple BooksおよびThoriumで動作を確認しています。

Dolphin版は、Dolphin EasyReaderで表示・朗読・文字ハイライトを確認した専用形式です。画面幅に合わせて文章が流れるリフロー型を採用しています。

利用できる機能は閲覧アプリや端末によって異なります。
